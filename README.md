# affilicard

汎用アフィリエイト商品カードの WordPress プラグイン。漫画・VOD・家電・雑貨など複数の商品ジャンルに対応する拡張可能設計。

## 主な機能

- アフィリエイト商品カード（カスタム投稿タイプ + Gutenberg ブロック）
- 複数プラットフォームのリンクボタン（Amazon / DMM / 楽天 等）
- WP-Cron による定期価格更新・リンク確認・予約投稿昇格
- ショートコード `[affilicard id="..."]` で外部から記事に埋め込み可能
- ジャンル拡張のための PHP インターフェース型の拡張パターン

## ステータス

骨組みのみ。実装は順次進める。
